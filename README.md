# Proyecto Juego - Ahorcado (HangMan)

## Descripción del proyecto

El presente proyecto implementa el Juego del Ahorcado. El objetivo del juego es adivinar una palabra secreta letra por letra. El jugador tiene un número limitado de intentos antes de que el "ahorcado" esté completo y pierda el juego. Cada letra incorrecta agrega una parte al dibujo del ahorcado.
